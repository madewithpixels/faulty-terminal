# faulty-terminal

A WebGL dot-matrix terminal effect for Webflow (and any HTML page). Renders an
animated field of glyphs with scanlines, glitch, mouse reactivity, and a
circular ripple reveal.

Served from jsDelivr as a single versioned script — one tag per page, no
pasted code to keep in sync across sites.

Built by [madewithpixels](https://madewithpixels.com).

---

## Use it

```html
<!-- once per page, before </body> -->
<script src="https://cdn.jsdelivr.net/gh/madewithpixels/faulty-terminal@1/dist/faulty-terminal.min.js"></script>
```

```html
<!-- anywhere you want the effect -->
<div class="faulty-terminal"></div>
```

That's the whole integration. Every `.faulty-terminal` element on the page is
initialised automatically; the base CSS is injected by the script.

| URL form | Behaviour |
|----------|-----------|
| `@1.5.0` | frozen to one build **(recommended)** |
| `@1` | latest 1.x — but jsDelivr caches range resolution for up to 12h, so it lags behind a fresh tag |
| `@main` | tip of the branch — 12h cache, **don't use in production** |

Webflow specifics — component setup, properties, interactions — are in
[`examples/Webflow usage.md`](./examples/Webflow%20usage.md), with a
paste-ready block in [`examples/webflow-embed.html`](./examples/webflow-embed.html).

Need it self-contained (no CDN)? [`faulty-terminal.embed.html`](./faulty-terminal.embed.html)
is the same build inlined into one file. It is generated by the build — don't
hand-edit it.

## Configuring

Three layers, later wins:

**1. Baked defaults** — the `TUNING` block at the top of `src/faulty-terminal.js`.
Change these when the art direction itself changes, then cut a release.

**2. Site-wide** — set before the script tag loads:

```html
<script>window.FaultyTerminalConfig = { tint: '#ff6b6b', brightness: 0.7 };</script>
<script src="https://cdn.jsdelivr.net/gh/madewithpixels/faulty-terminal@1/dist/faulty-terminal.min.js"></script>
```

**3. Per element, from a Webflow component property** — an inert
`<template data-ft-config>` inside the container. Each child names an option in
`data-ft-k` and carries the value as its text:

```html
<div class="faulty-terminal">
  <template data-ft-config>
    <i data-ft-k="tint">#ff6b6b</i>
    <i data-ft-k="brightness">0.7</i>
  </template>
</div>
```

Template content is never rendered, never styled and never enters the
accessibility tree, and the script removes the node once it has read it — so
after init the DOM is unchanged. This exists because Webflow can bind a
component property to an element's **text**, but not to a custom attribute's
value; the template is what makes every option settable per instance.

**4. Per element, by hand** — `data-ft-opts` with single-quoted JSON (Webflow's
attribute field won't take nested double quotes):

```html
<div class="faulty-terminal" data-ft-opts="{'tint':'#ff6b6b','ripple':false}"></div>
```

**Every option also has its own attribute.** Any `data-ft-*` attribute maps to
the matching option key, kebab-case to camelCase — which is what makes each one
bindable as a Webflow component property:

```html
<div class="faulty-terminal"
     data-ft-tint="#ff6b6b"
     data-ft-brightness="0.7"
     data-ft-ripple-duration="1400"
     data-ft-curvature="0.1"></div>
```

Values everywhere are coerced by the type of the default: `"0.7"` → number, `"false"` →
boolean, colours and selectors stay strings. **Empty values are ignored**, so an
unfilled Webflow component property falls back to the default instead of
clobbering it. Unknown keys are dropped with a console warning.

Two aliases and one flag don't follow the pattern:

| Attribute | Effect |
|-----------|--------|
| `data-ft-bg="#2b464e"` | → `bgColor` |
| `data-ft-origin="#my-logo"` | → `rippleOriginSelector` |
| `data-ft-no-ripple` | disable the reveal (bare attribute) |
| `data-ft-debug` | force the debug panel on |

## JS API

`window.FaultyTerminal` (also an ES module default export):

| Member | Description |
|--------|-------------|
| `init(root?)` | Initialise any uninitialised `.faulty-terminal` inside `root` (default `document`). Idempotent — call after injecting markup. |
| `retrigger(target?)` | Replay the ripple. Pass an element, a selector, an index, or nothing for all. |
| `instances` | Live array of running instances (`{ ctn, opts, setParam, getParam, retrigger }`). |
| `defaults` / `tuning` | The resolved default objects, for reference. |
| `version` | Build version string. |

## Ripple reveal

A circular wave sweeps outward from an origin point, revealing the field as it
passes. It fires when the container gains the class `does-ripple` — typically
from a Webflow interaction on page load or scroll-into-view.

```html
<div class="faulty-terminal does-ripple"></div>
```

By default it expands from the container's centre; `rippleOriginSelector`
(or `data-ft-origin`) points it at any element on the page.

### Aftershock

A secondary ring fires automatically after the main ripple, using the same
origin and gradient. `aftershockTriggerAt` sets how far through the main ripple
it launches (`0.82` = 82%); `aftershockDelay` adds an optional ms pause on top.

## Debug panel

**On by default** — this is an MWP-internal component, so the panel ships
enabled. Turn it off for a given site with
`FaultyTerminalConfig = { debugPanel: false }`. When it is off, `?ft-debug` in
the URL or a `data-ft-debug` attribute still brings it back on demand.
Backtick (`` ` ``) toggles it.

With more than one terminal on a page, **◀ ▶** switches between them. The
selected instance is outlined on the page and named in the panel header after
its id or its parent's class, so it's clear which one the sliders are driving.
**Alt-click** a terminal to bring it straight into the panel.

- **↺ re-trigger** — replays the reveal
- **⎘ copy values** — copies the current state as a `const TUNING = { ... }`
  block, ready to paste into `src/faulty-terminal.js`

Tune on a real published page, copy, paste into src, rebuild, release.

## Development

```
src/faulty-terminal.js    # the whole effect — single source of truth
src/faulty-terminal.css   # base CSS, inlined into the bundle
src/embed.js              # browser entry (side-effect import)
scripts/build.mjs         # esbuild
dist/                     # built output — COMMITTED, this is what jsDelivr serves
preview.html              # local dev page, loads dist/, debug panel forced on
```

```bash
npm install
npm run build     # or: npm run watch
open preview.html
```

`ogl` is bundled into `dist/` — one request, no third-party CDN at runtime.

### Releasing

`dist/` is committed on purpose: jsDelivr serves files straight out of the tag.

```bash
npm version minor          # bumps package.json + tags
npm run build              # version string is baked into the bundle
git add -A && git commit --amend --no-edit
git push && git push --tags
```

Then hit `https://cdn.jsdelivr.net/gh/madewithpixels/faulty-terminal@<tag>/dist/faulty-terminal.min.js`
once to warm the cache. Existing `@1` sites pick it up as their cache expires
(up to 12h; a pinned `@1.0.0` never moves).

## TUNING reference

All visual parameters live in the `TUNING` block in `src/faulty-terminal.js`,
and every key can be overridden at runtime via `FaultyTerminalConfig` or
`data-ft-opts`.

### Ripple

| Key | Default | Description |
|-----|---------|-------------|
| `rippleDuration` | `1150` | Main ring travel time (ms) |
| `rippleColorFalloff` | `4.30` | Trail decay curve — higher = shorter, sharper tail |
| `rippleColorAmbient` | `0.34` | Trail colour strength behind the ring (0–1) |
| `rippleColorStrength` | `1.80` | Overall colour intensity multiplier |
| `blendMode` | `0` | 0 screen · 1 add · 2 overlay · 3 soft |
| `rippleBrightness` | `0.10` | Glyph brightness boost at the ring front |
| `rippleBrightnessFalloff` | `0.14` | Width of the brightness glow band |
| `rippleFadeOut` | `375` | Duration (ms) to fade trail colour out after the ring completes |
| `rippleWobble` | `1.00` | Wave-front wobble |
| `rippleWarp` | `1.00` | Shockwave warp |
| `impactBurst` | `2.00` | Flash at the moment of impact |

### Aftershock

| Key | Default | Description |
|-----|---------|-------------|
| `aftershock` | `true` | Enable the secondary ring |
| `aftershockTriggerAt` | `0.05` | Main ripple progress (0–1) at which it launches |
| `aftershockDelay` | `0` | Additional delay (ms) after the trigger point |
| `aftershockDuration` | `1350` | Aftershock ring travel time (ms) |
| `aftershockStrength` | `0.30` | Aftershock colour intensity |

### MWP glyphs

| Key | Default | Description |
|-----|---------|-------------|
| `mwpColorStrength` | `0.47` | Intensity of the MWP brand palette overlay |
| `mwpDensity` | `0.27` | How many cells carry M/W/P letterforms |
| `mwpFlickerSpeed` | `0.10` | Master timing for decode/flicker |
| `mwpWaveDuration` | `1050` | Heart-wave travel time (ms) |
| `mwpWaveAt` | `0.05` | Ripple progress at which the heart wave launches |
| `mwpLegible` | `0.89` | Fraction of time glyphs read as letters — lower = more coded |
| `mwpGlitch` | `0.85` | How glitchy the decode/resolve is |
| `heartStrength` | `2.00` | Heart glow |
| `heartScale` | `1.00` | Heart size |
| `heartFalloff` | `1.50` | Heart edge softness |

### Brand cycle

Rotates the glyph colour through the three brand colours. Off by default, so
existing pages are unchanged until `brandMode` is turned up. The colours are the
same CSS variables the ripple uses, so they follow the site's palette.

| Key | Default | Description |
|-----|---------|-------------|
| `brandMode` | `0` | 0 off · 1 whole field · 2 gradient sweep · 3 per glyph |
| `brandStrength` | `0.60` | Opacity of the brand colour over the base tint (0–1) |
| `brandSpeed` | `0.15` | How fast the cycle advances |
| `brandSoftness` | `0.60` | Crossfade width — 0 = hard cuts, 1 = continuous blend |
| `brandScale` | `1.00` | Gradient tightness (mode 2 only) |
| `brandAngle` | `0.25` | Gradient direction, 0–1 = full turn (mode 2 only) |

Mode 1 makes the whole field one colour at a time. Mode 2 shows all three at
once as a gradient drifting across the field. Mode 3 gives every glyph its own
colour and offset, so the field shimmers between all three at once.

### Field

| Key | Default | Description |
|-----|---------|-------------|
| `brightness` | `0.20` | Overall field brightness |
| `glyphGamma` | `3.60` | Glyph contrast curve |
| `scanlineIntensity` | `1.00` | Scanline strength |
| `glitchAmount` | `1.90` | Horizontal glitch displacement |
| `flickerAmount` | `1.10` | Flicker intensity |
| `noiseAmp` | `1.00` | Noise field amplitude |
| `curvature` | `0.30` | CRT barrel distortion (0 = flat) |
| `mouseStrength` | `0.60` | Mouse ripple reactivity |
| `timeScale` | `0.45` | Animation speed multiplier |
| `digitSize` | `1.25` | Glyph scale within each cell |
| `tiltStrength` | `0.40` | Device-tilt reactivity (mobile) |
| `vignette` | `0.30` | Edge darkening |
| `retraceSweep` | `1.00` | CRT retrace bar |
| `noiseDetail` | `0.35` | Fine noise detail |
| `phosphor` | `250` | Phosphor persistence (ms), `phosphorOn` toggles |

## Performance

`autoTune: true` monitors live frame rate and scales render resolution between
`renderScaleMin` (0.28×) and `renderScaleMax` (1×) to stay above `fpsHigh`.
Rendering pauses when the element scrolls off-screen or the tab is hidden.

Bundle: ~90KB minified, ~27KB gzipped, ogl included.

---

## Browser support

Requires WebGL 1.0 — all modern browsers. Degrades to a blank canvas without it.
